## Featured Projects

### [Expense Tracker API](https://github.com/TeeThembela/Expense-Tracker-API)

**Status:** Completed

**Overview:**  
A backend REST API for personal expense management, allowing users to manage expenses, categories, and budgets. Built with a focus on secure authentication, user data isolation, and session management.

**Key Features:**
- Expense management with filtering by period and custom date ranges.
- Category and budget management with inline budget warnings.
- JWT-based authentication using short-lived access tokens and rotating refresh tokens.
- Secure refresh token storage using HttpOnly, Secure, and SameSite=Strict cookies.
- Single-device and all-device logout functionality.
- Administrative endpoints for account management.
- API documentation using Swagger UI.

**Technical Highlights:**
- Implemented user-level resource isolation using Spring Security method expressions.
- Added session revocation for individual devices and all active devices.
- Containerised the application and database using Docker Compose.

**Technologies:** Java 22, Spring Boot 4, Spring Security, Spring Data JPA, JJWT, PostgreSQL 17, Docker, Maven.
